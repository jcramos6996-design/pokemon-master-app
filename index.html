Cómo buscar

Escribe nombres o etiquetas en el buscador. También puedes usar los botones de Filtros.

  • agua gen1 → espacio = las dos cosas (Y), si son de secciones distintas.
  • agua/tierra → / = una u otra (O).
  • agua+tierra → + = las dos a la vez (Y), por ejemplo doble tipo.
  • -fuego → - delante = excluir.
  • 025 → número de Pokédex. eevee → muestra también su línea evolutiva.

Botones: toca para activar (azul). Mantén pulsado para excluir (rojo). Toca otra vez para quitar. En las secciones con Coincidir, cambia entre «Cualquiera» (O) y «Todas» (Y, verde).

Los tipos también se pueden escribir en español: agua, fuego, planta…
